1设计任务与已知条件

为一条水平带式输送机设计传动滚筒轴。载荷平稳，每日工作 8 h，常温、无腐蚀。

参数符号数值单位
输送带牵引力F3000N
带速v1.2m/s
滚筒直径D400mm
传动总效率η0.85—
轴承跨距L450mm

2功率、转速与扭矩

输送带有效功率 P_w = F·v/1000 = 3000×1.2/1000 = 3.60 kW 电机所需功率 P_m = P_w/η = 3.60/0.85 = 4.24 kW → 选 5.5 kW 标准电机 滚筒转速 n = 60v/(πD) = 60×1.2/(π×0.4) = 57.3 r/min 配减速器 i=25 n' = 1440/25 = 57.6 r/min，带速 1.207 m/s，误差 0.6% 滚筒轴扭矩 T = 9550·P_w/n' = 9550×3.60/57.6 = 597 N·m

选 5.5 kW 是留了 1.3 倍功率余量，用于启动和瞬时过载；减速器速比取标准值 25，带速偏差 0.6%，在输送机允许范围内。

3轴径初估（扭转强度）

材料选 45 钢正火，取 A₀=118，按扭转强度初估最小轴径：

d ≥ A₀·(P/n)^(1/3) = 118×(3.60/57.6)^(1/3) = 118×0.3969 = 46.8 mm 向上取标准直径 → d₀ = 48 mm

这一步只保证扭转强度，是「速算工具箱」的轴径模块给出的初值。滚筒轴还要承受带张力产生的弯矩，必须复核。

4弯扭组合强度校核

取带与滚筒的摩擦系数 μ=0.3、包角 180°，则 F₁/F₂=e^μθ≈2；由 F₁−F₂=3000 N 得 F₁=6000 N、F₂=3000 N，两股带张力合力近似为：

R = F₁ + F₂ = 9000 N

载荷居中，最大弯矩在跨中：

M = R·L/4 = 9000×0.45/4 = 1012.5 N·m M_eq = √(M² + (αT)²) = √(1012.5² + (0.6×597)²) = 1074 N·m （α=0.6，扭矩按脉动循环） d ≥ [32·M_eq/(π·[σ₋₁])]^(1/3) = [32×1074×10³/(π×60)]^(1/3) = 56.7 mm 向上取标准直径 → d = 60 mm 实际应力 σ = M_eq/W = 1074×10³/(π×60³/32) = 50.7 MPa < [σ₋₁]=60 MPa ✓
关键结论：扭转初估只要 48 mm，弯扭校核后必须 60 mm。滚筒轴的主要矛盾是带张力产生的弯矩，不是扭矩——只看第 3 步会设计出偏细的轴。

5键连接校核

轴颈 60 mm，选 A 型平键 18×11，键长 80 mm，材料 45 钢，许用挤压应力取 100 MPa：

σ_p = 4T/(d·h·l) = 4×597×10³/(60×11×80) = 45.5 MPa < 100 MPa ✓

6轴承选型与寿命

轴颈 60 mm，选深沟球轴承 6212（C=47.5 kN，C₀=32.8 kN）。两端对称布置，每端径向载荷 R/2=4.5 kN，无轴向力，P=4.5 kN：

L₁₀ₕ = (10⁶/(60n))·(C/P)³ = (10⁶/(60×57.6))×(47.5/4.5)³ = 3.4×10⁵ h

寿命远超 20000 h 的设计目标。这里轴承尺寸是由轴颈结构决定的，不是寿命算出来的——这是输送机滚筒轴的典型特征。

7结论与可改进点

弯扭校核后轴径60 mm通过
实际弯曲应力50.7 MPa通过
键连接挤压应力45.5 MPa通过

可改进点：若把轴承跨距从 450 mm 缩到 350 mm，弯矩降为 787 N·m，轴径可回到 55 mm 以下，整轴减重约 12%；代价是滚筒两端的安装空间变紧，需要重新布置轴承座。
